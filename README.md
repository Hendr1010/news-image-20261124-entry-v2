Entry for the make.fun bounty **news-image-20261124**: sum up 24 November's world news in one image.

The image is a newspaper front page for 24 November 2026. Its lead story is Ukraine sinking a Russian warship off Libya, with the day's other big stories alongside it: Russia's warning to Estonia, the collapse of COP31 in Antalya, the US–Iran standoff at Hormuz, and Nvidia bringing back Jensen Huang.

## How it runs

`main.ts` (Node, standard library only) finds `entry.png` next to itself — from the program file's own location, never from the working directory — and copies it byte-for-byte to `/output/entry.png`.
